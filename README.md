# E-Procurement Interactive Prototype

Interactive prototype for the end-to-end procurement process, covering sourcing, Technical Bid Evaluation (TBE), Commercial Bid Evaluation (CBE), negotiation, and award determination.

## Features

- PR Dashboard and PR Workspace
- Vendor participation and quotation management
- TBE evaluation per vendor and PR line item
- TBE evidence attachment and Comply / Not Comply decisions
- Live CBE price calculations
- Vendor quotation attachments and version history
- Price negotiation and revised quotation submission
- Final CBE submission and locking
- Commercial Committee Meeting (CCM) / PAL approval simulation
- Award notification and Purchase Order workflow
- CBE data export to CSV

## How to Run

1. Download or clone this repository.
2. Open `index.html` using a modern web browser.
3. Navigate through the PR Dashboard and explore the procurement workflow.

No installation or additional software is required.

## Important Notes

This is a front-end demonstration prototype using sample data.

It is not connected to:
- SAP or other ERP systems
- Actual vendor accounts or authentication
- Email services
- Centralized document repositories
- Live procurement databases

File attachments and workflow changes are simulated within the current browser session. They are not permanently stored or synchronized between users.
